# Model the data flow diagram

- **EmbedRisk: Open DFD canvas (native)** edits components, data flows and trust boundaries.
- **EmbedRisk: Open DFD in draw.io editor** offers a draw.io-based alternative.
- Drill into a component with **Ctrl+Alt+Down** (layer down) and return with **Ctrl+Alt+Up** (layer up).

Flows that cross a trust boundary are where most threats emerge.
